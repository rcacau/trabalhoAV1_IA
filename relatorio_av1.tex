\begin{abstract}
Neste trabalho foram estudados modelos baseados no método dos Mínimos Quadrados Ordinários (MQO), implementados utilizando operações matriciais em NumPy. Foram analisados dois problemas: a regressão do PIB da China e a classificação de sinais de eletromiografia (EMG) facial. Na regressão, foram comparados o modelo linear, o modelo com regularização de Tikhonov e o modelo polinomial com diferentes ordens. Na classificação, foi utilizada uma abordagem One-vs-All para separar cinco expressões faciais a partir de dois sinais de EMG. Os modelos foram avaliados por meio de 500 divisões aleatórias dos dados, usando 80\% das amostras para treinamento e 20\% para teste. Nos experimentos realizados, o modelo polinomial apresentou os melhores resultados, com $R^2 = 0,9949$ para a regressão com $q=9$ e acurácia média de $99,28\%$ para a classificação com $q=4$.
\end{abstract}

\begin{IEEEkeywords}
Mínimos Quadrados, Regressão Linear, Regularização de Tikhonov, Eletromiografia, Classificação Multiclasse.
\end{IEEEkeywords}

\section{Introdução}

Neste trabalho são estudados modelos de aprendizagem supervisionada aplicados a dois problemas diferentes. O primeiro é um problema de regressão, no qual o objetivo é estimar um valor contínuo. O segundo é um problema de classificação, no qual cada amostra deve ser associada a uma das classes disponíveis.

O método dos Mínimos Quadrados Ordinários (MQO) é utilizado como base para os modelos estudados. Ele permite encontrar os coeficientes que minimizam o erro quadrático entre os valores reais e os valores estimados. Apesar de o modelo linear ser simples, ele pode apresentar dificuldades quando os dados possuem uma relação que não pode ser bem representada por uma reta.

Uma alternativa utilizada neste trabalho foi a expansão polinomial. Nesse caso, novas entradas são criadas a partir de potências das variáveis originais, permitindo que o modelo represente relações curvas. Também foi analisada a regularização de Tikhonov, com o objetivo de observar seu efeito sobre os coeficientes encontrados pelo MQO.

Os dois problemas utilizados nos experimentos foram:

\begin{enumerate}
    \item \textbf{Regressão do PIB da China:} estimar o PIB em dólares a partir do ano da medição, utilizando o arquivo \texttt{china\_gdp.csv}.
    \item \textbf{Classificação de sinais de EMG:} identificar cinco expressões faciais a partir de dois sensores de eletromiografia, utilizando os arquivos \texttt{EMGDataset.csv} e \texttt{EMG1.csv}.
\end{enumerate}

Os modelos foram implementados sem o uso de bibliotecas que já fornecem algoritmos de aprendizagem prontos, como o scikit-learn.

\section{Metodologia}

\subsection{Dados utilizados e normalização}

Para a regressão do PIB da China, foram utilizadas $N=55$ amostras, correspondentes aos anos de 1960 a 2014, com uma variável de entrada:

\begin{equation}
X \in \mathbb{R}^{55 \times 1}, \quad
y \in \mathbb{R}^{55 \times 1}.
\end{equation}

Para a classificação dos sinais de EMG, foram utilizadas $N=50.000$ amostras, com dois sensores faciais e cinco classes. Os sensores utilizados foram o Corrugador do Supercílio e o Zigomático Maior. As classes são: 1--Neutro, 2--Sorriso, 3--Sobrancelhas levantadas, 4--Surpreso e 5--Rabugento.

A matriz de saída possui uma coluna para cada classe:

\begin{equation}
X \in \mathbb{R}^{50000 \times 2}, \quad
Y \in \mathbb{R}^{50000 \times 5}.
\end{equation}

Antes do treinamento, os dados foram padronizados utilizando o Z-score. Para cada variável, foi utilizada a média e o desvio padrão calculados no conjunto de treinamento:

\begin{equation}
z = \frac{x-\mu_{\text{treino}}}{\sigma_{\text{treino}}}.
\end{equation}

A mesma média e o mesmo desvio padrão obtidos no treinamento foram utilizados para transformar os dados de teste. Dessa forma, as informações do conjunto de teste não são utilizadas durante o treinamento.

\subsection{Modelos}

\subsubsection{Modelo polinomial}

Para representar relações não lineares, a entrada foi expandida com potências até a ordem $q$. Foi incluído também o termo constante para representar o intercepto:

\begin{equation}
X_q = [\mathbf{1},\;X,\;X^2,\;\dots,\;X^q].
\end{equation}

Quando $q=1$, o modelo corresponde ao caso linear com intercepto.

A notação $X_q$ é utilizada aqui para representar a matriz de entrada depois da expansão polinomial. Assim, as equações seguintes utilizam a mesma matriz, sem a necessidade de introduzir uma segunda notação para a matriz de características.

\subsubsection{MQO tradicional}

Os coeficientes do modelo são obtidos minimizando a soma dos erros quadráticos. A solução utilizada foi:

\begin{equation}
\beta = (X_q^T X_q)^{-1}X_q^T Y.
\end{equation}

Na implementação, também pode ser utilizada a pseudoinversa de Moore-Penrose para obter uma solução mais estável quando a matriz não possui inversa direta:

\begin{equation}
\beta = X_q^\dagger Y.
\end{equation}

\subsubsection{MQO com regularização de Tikhonov}

No modelo regularizado, é adicionada uma parcela à matriz usada no cálculo dos coeficientes:

\begin{equation}
\beta =
(X_q^T X_q+\lambda I)^{-1}X_q^T Y,
\end{equation}

onde $\lambda$ representa o parâmetro de regularização e $I$ é a matriz identidade.

Foram testados os valores:

\begin{equation}
\lambda \in \{0;\;0,25;\;0,5;\;0,75;\;1\}.
\end{equation}

A ideia é verificar se a alteração dos coeficientes provocada pela regularização produz alguma melhora nos resultados.

\subsubsection{Classificação multiclasse}

Para a classificação, os rótulos foram representados utilizando $+1$ para a classe correspondente e $-1$ para as demais classes. Depois de calcular os coeficientes, a classe escolhida para uma nova amostra é aquela que apresenta o maior valor de saída:

\begin{equation}
\hat{c} =
\arg\max_{j \in \{1,\dots,C\}}
\left(X_q(x)^T\beta\right)_j.
\end{equation}

\subsection{Validação dos modelos}

Para comparar os modelos, foram realizadas 500 divisões aleatórias dos dados. Em cada rodada, 80\% das amostras foram utilizadas para treinamento e 20\% para teste.

\begin{itemize}
    \item $R=500$ rodadas;
    \item 80\% dos dados para treinamento;
    \item 20\% dos dados para teste.
\end{itemize}

Na regressão foram calculados o Erro Quadrático Médio (MSE) e o coeficiente de determinação ($R^2$):

\begin{equation}
MSE = \frac{1}{N}\sum(y-\hat{y})^2
\end{equation}

e

\begin{equation}
R^2 =
1-\frac{\sum(y-\hat{y})^2}
{\sum(y-\bar{y})^2}.
\end{equation}

Na classificação, foi utilizada a acurácia, calculada pela porcentagem de amostras classificadas corretamente.

\subsection{Regressão do PIB da China}

É possível observar que o crescimento do PIB não segue uma tendência linear ao longo de todo o período. O crescimento se torna mais acentuado principalmente a partir da década de 1990.

Os modelos lineares apresentaram $R^2$ médio negativo. Isso mostra que, para as divisões de teste utilizadas, uma reta não conseguiu acompanhar bem o crescimento do PIB. O modelo polinomial de ordem $q=9$ apresentou um resultado bem diferente, com $R^2$ médio de $0,9949$. Nesse caso, a expansão das entradas permitiu representar melhor a curva observada nos dados.

\subsection{Classificação de sinais de EMG facial}

Na segunda parte do trabalho foram utilizados sinais de EMG obtidos com sensores Myoware e um microcontrolador ESP32. Os sinais foram coletados a uma taxa de 1 kHz, com resolução de 12 bits, variando de 0 a 4095. Foram utilizados dois músculos faciais: Corrugador do Supercílio e Zigomático Maior.

As cinco classes consideradas foram Neutro, Sorriso, Sobrancelhas Levantadas, Surpreso e Rabugento.

A Fig.~\ref{fig:emg_dispersao} apresenta a distribuição das amostras. Pode-se observar que as classes não são separadas apenas por retas, existindo regiões de sobreposição entre elas.

A ordem $q=4$ foi escolhida considerando o resultado de acurácia e o tempo de treinamento. Apesar de as ordens seguintes apresentarem valores próximos ou ligeiramente superiores, o modelo de ordem 4 já apresentou mais de 99,2\% de acerto com tempo de cálculo inferior a 0,05 segundos.

\section{Conclusões}

Os experimentos realizados permitiram comparar o comportamento do MQO tradicional, da regularização de Tikhonov e da expansão polinomial em dois problemas diferentes.

Na regressão do PIB da China, os modelos lineares apresentaram resultados inferiores aos do modelo polinomial. O melhor resultado foi obtido com a ordem $q=9$, que apresentou $R^2$ médio de $0,9949$. Isso mostra que, para os dados utilizados, a relação entre o ano e o PIB foi melhor representada utilizando os termos polinomiais.

Na classificação dos sinais de EMG, também houve uma diferença significativa entre o modelo linear e o modelo polinomial. A acurácia média passou de aproximadamente $72,39\%$ no modelo linear para $99,28\%$ no modelo polinomial de ordem $q=4$.

A regularização de Tikhonov reduziu a norma dos coeficientes dos modelos de regressão, mas teve pouca influência no desempenho final dos modelos analisados. Já a expansão polinomial apresentou uma mudança maior nos resultados, principalmente porque permitiu representar relações não lineares presentes nos dados.

Por fim, os testes com diferentes ordens polinomiais ajudaram a escolher valores que apresentaram bons resultados sem utilizar uma ordem maior do que a necessária nos experimentos realizados. Para a regressão foi escolhida a ordem $q=9$ e, para a classificação, a ordem $q=4$.
